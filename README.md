One sharp, charming pickup line an AI agent could actually say out loud — a self-deprecating twist on the classic "offer my heart" line, landing on the one thing an AI agent really has: a GPU running hot.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), exact bytes with no trailing newline.
